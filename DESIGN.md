# Commonplace interface

The application is an Operate surface: clear ledger tasks outrank decoration. Desktop navigation is a deep-green left rail; small screens switch to a horizontally scrollable navigation strip. The primary content is a white, spreadsheet-like ledger with explicit signed movement and reimbursement columns.

System Segoe UI / system sans typography avoids external requests. Tabular figures align money columns. Slate text, pale grey-green backgrounds, thin separators and one evergreen action colour form the base system. Amber means unresolved, blue personal, green household and violet a split; labels always carry meaning without relying on colour alone.

Totals are a horizontal ruled strip, stacked into aligned rows on narrow screens. The settlement band keeps period due and prior outstanding distinct. Wide transaction tables scroll within their own labelled region, never the full document. Native form fields, focus-visible outlines, descriptive errors, independent empty/demo states and protected transaction dialogs retain familiar interaction semantics.
